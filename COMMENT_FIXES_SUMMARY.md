# Comment Section & Content Moderation Fixes

## Changes Made:

### 1. Content Moderation (Posts & Comments)
- **ForumService.java**: 
  - Posts with inappropriate content now throw `IllegalArgumentException` instead of being set to PENDING_REVIEW
  - All posts are now created with "PUBLISHED" status
  - Tags are now ALWAYS auto-generated using Groq API (removed manual tag option)
  - Comments with inappropriate content throw exception and are not created

- **CreatePostDialogController.java**:
  - Added try-catch to handle moderation exceptions
  - Shows warning modal when inappropriate content is detected
  - Post is NOT created if moderation fails

- **CommunityFeedController.java & CommunityFeedViewController.java**:
  - Added try-catch in `postComment()` method
  - Shows warning modal when comment contains inappropriate content
  - Comment is NOT created if moderation fails

### 2. Comment Status Fix
- Changed comment status from "ACTIVE" to "PUBLISHED" in both controllers
- This matches the ForumService convention and the database schema default

### 3. Comment Counter
The comment counter should now work because:
- Comments are created with "PUBLISHED" status
- SQL query counts all comments where `status <> 'DELETED'`
- After posting/deleting a comment, `loadPosts()` is called which refreshes all post data from database
- The database query dynamically calculates comment_count using a subquery

## Testing:

### To test comment counter:
1. Create a post
2. Click the comment button - should show "Comment (0)"
3. Add a comment
4. The button should update to "Comment (1)"
5. Add another comment - should show "Comment (2)"
6. Delete a comment - should decrease the count

### To test content moderation:
1. Try to create a post with words like "fuck" or "shit"
2. Should see a warning modal
3. Post should NOT be created
4. Same for comments

### To test auto-generated tags:
1. Create a post with any title and content
2. The tag should be automatically generated by Groq API
3. Manual tag field is ignored

## Potential Issues:

If comment counter still doesn't work:
1. Check database - verify comments are being inserted with status='PUBLISHED'
2. Check if `loadPosts()` is actually being called after comment creation
3. Verify the SQL subquery is returning correct count
4. Check browser/UI cache - try refreshing the entire view

## SQL Query for Manual Verification:
```sql
SELECT p.id, p.title, 
       (SELECT COUNT(*) FROM forum_comments fc 
        WHERE fc.post_id = p.id AND fc.status <> 'DELETED') AS comment_count
FROM forum_posts p;
```
